Simon's blog post celebrates a couple of Python 3.15 features Simon is excited about, but most importantly shines some light on another obvious side of the Python 3.15 release that I hadn't thought about.

Now that 3.15 is released, 3.10 is no longer officially supported.
This means that it's “reasonable” — for some measure of “reasonable” — to assume Python 3.11 in your projects.
Which means it's time to revisit the “What's new in Python 3.11” because those features are now available in _every_ supported version of Python!

This is obvious in hindsight, but not something I see folks talking about.
